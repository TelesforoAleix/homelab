# 00 — Budget and Cost Model

Home Lab tracks the cost of the **actual reference implementation** and separates it from rough reproduction estimates.

## Cost categories

### One-time

- server hardware
- RAM/storage upgrades
- adapters/cables where project-specific
- future GPU/local-AI node

### Recurring

- AI subscriptions
- cloud services
- domain/DNS services if introduced
- hosted infrastructure if introduced

### Usage-based

- model APIs
- model gateways
- speech-to-text APIs
- storage/compute services
- token usage

## Reference-build policy

Record what was actually paid rather than pretending sunk/pre-existing subscriptions are free. If a subscription existed before Home Lab, label that clearly rather than assigning an invented incremental cost.

Track both DKK and EUR where practical. For historical purchases, record the conversion method/date if exact EUR accounting matters.
