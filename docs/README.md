# Project Documentation

> **Version one closed on 2026-09-18.** This directory is the preserved operational record. Begin
> with the [closure handover](handovers/project-closure.md) and the final
> [current architecture](architecture/current-architecture.md). Target and roadmap documents also
> contain unfinished historical intent.

`docs/` contains concise operational truth about the actual Home Lab reference implementation.

It is intentionally different from `guide/`, which contains learning-oriented explanations.

## Structure

- `architecture/` — current and target system architecture
- `decisions/` — Architectural Decision Records (ADRs)
- `build-log/` — chronological record of what actually happened
- `reference/` — current hardware, software, costs, and project state
- `handovers/` — phase briefs and structured handovers
- `templates/` — reusable documentation templates
- `standards/` — project-wide documentation and completion rules
