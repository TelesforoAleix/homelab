# ADR-003: Use Ubuntu Server LTS

- **Status:** Accepted
- **Date:** 2026-09-08

## Context

The target system is an always-on headless server. A desktop GUI would consume resources and hide useful server-administration learning.

## Decision

Install Ubuntu Server LTS and operate the M700 headlessly after initial setup.

## Alternatives considered

Keep Windows; use Ubuntu Desktop; use another Linux distribution.

## Consequences

The project standardizes its guides around Ubuntu Server while acknowledging that many concepts generalize to other Linux systems.
