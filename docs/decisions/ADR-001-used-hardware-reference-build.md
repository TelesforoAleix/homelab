# ADR-001: Use inexpensive used hardware as the reference platform

- **Status:** Accepted
- **Date:** 2026-09-08

## Context

The project is intended to make AI infrastructure experimentation accessible and affordable. The owner selected a used Lenovo ThinkCentre M700 Tiny for 700 DKK.

## Decision

Use inexpensive used hardware for the canonical orchestration node and document the real purchase cost. Provide specification-based guidance so readers are not locked to the exact Lenovo model.

## Alternatives considered

Buy new server hardware; begin with a cloud VM; begin with a GPU workstation.

## Consequences

The guide must account for hardware variation and used-market uncertainty. The project gains a concrete budget-oriented reference build.
